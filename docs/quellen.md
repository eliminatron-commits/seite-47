# Quellen der Wahlprogramme

Alle PDFs liegen unter `data/programme/<region>/<partei>.pdf`. Bezugsdatum: 7. September 2026.
Seitenangaben in der Datenbasis beziehen sich auf die **PDF-Seitenzahl** (wie von PDF.js
gezählt), nicht auf die aufgedruckte Seitenzahl. Jede Angabe wurde maschinell gegen das PDF
geprüft: `python .claude/pdftool.py pruefe`.
